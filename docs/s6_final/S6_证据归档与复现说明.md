## 8. No-test Boundary

S6 是 validation-only。不得使用 test 结果调整：

- K；
- lambda；
- source bonus；
- projection；
- ranker；
- thresholds；
- promotion policy；
- checkpoint；
- SID。

## 9. No-further-tuning Boundary

S6-6R 是 S6 中最后允许的 lightweight-ranker revision。它失败后，S6 ranker tuning 停止。后续如果继续研究 ranker，必须作为新阶段、新协议、新 validation gate，不得回填 S6。

## 12. Rollback Rules

只回滚 final documentation metadata：

```bash
python3 - <<'PY'
from pathlib import Path
import shutil

for path in [
    Path("docs/s6_final"),
    Path("results/s6_cost_aware_aux/Industrial_and_Scientific/s6_final_archive"),
]:
    if path.is_dir():
        shutil.rmtree(path)
PY
```

不要删除历史 S6 evidence、candidate 文件、union 文件、ranker 输出或 incoming bundles。
